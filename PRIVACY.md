# Privacy Policy — Shorts Blocker

_Last updated: November 2026_

Shorts Blocker does not collect, store or share any personal data.

- The extension runs only on youtube.com and changes how the page looks on your device.
- It does not read your history, account, or what you watch.
- Every few hours it downloads a public list of CSS selectors (`selectors.json`) from GitHub. No information about you is sent in this request beyond what any web request contains (such as your IP address, which GitHub may log under its own policy).
- There are no analytics, ads or trackers.

Questions: open an issue in this repository.

---

# Политика конфиденциальности — Блокировщик Shorts

Блокировщик Shorts не собирает, не хранит и не передаёт персональные данные.

- Расширение работает только на youtube.com и меняет вид страницы на твоём устройстве.
- Оно не читает историю, аккаунт и то, что ты смотришь.
- Раз в несколько часов оно скачивает с GitHub публичный список CSS-селекторов (`selectors.json`). Кроме того, что есть в любом веб-запросе (например, IP-адрес, который GitHub может записывать по своей политике), никаких данных о тебе не отправляется.
- Нет аналитики, рекламы и трекеров.
